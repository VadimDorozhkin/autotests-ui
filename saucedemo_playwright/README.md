# Saucedemo Playwright Autotests Project

Этот проект представляет собой профессиональный набор автотестов для сайта https://www.saucedemo.com/, спроектированный с использованием паттерна Page Object Model (POM) и модульной структуры фикстур pytest.

Проект изолирован в этой папке, чтобы не смешиваться с вашими основными тестами.

## Запуск тестов:
Для запуска тестов именно этого проекта перейдите в эту директорию:
```bash
cd saucedemo_playwright
pytest
```
